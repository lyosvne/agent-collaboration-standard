# Agent Entry Checklist

Use this checklist when configuring a coding agent or opening a new project.

## Global Rules

- [ ] Agent can find `C:\Users\Admin\.agent-collaboration\START_HERE.md`.
- [ ] Agent can read the unified standard.
- [ ] Agent knows GitHub is the hard code sync point.
- [ ] Agent uses the shared start and finish output fields.
- [ ] Agent knows the safety red lines.

## Tool Skills

- [ ] `collaboration-bootstrap` is available.
- [ ] `cross-agent-handoff` is available.
- [ ] `git-truth-guardian` is available.
- [ ] `verification-gate` is available.
- [ ] `debugging-gate` is available.
- [ ] `plan-gate` is available.
- [ ] `review-gate` is available.
- [ ] `security-boundary-gate` is available.

## Project Entry

- [ ] Project has an entry rule file, such as `CLAUDE.md`, `GEMINI.md`, `AGENTS.md`, `.trae/rules`, or README.
- [ ] Project commands for build, test, and run are discoverable.
- [ ] Project source of truth is explicit.
- [ ] Runtime state is separated from Git truth.

## Handoff

- [ ] Agent can produce a handoff pack.
- [ ] Agent can read a handoff pack from another tool.
- [ ] Handoff includes verification gaps and next action.
