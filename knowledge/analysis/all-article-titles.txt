[2026年4月14日 16:37] Anthropic 封了 OpenClaw 之后，自己下场了。 4 月 4 日，Anthropic 调整了 Claude 订阅条款，限制 Pro / Max 订阅额度用于 OpenClaw 等第三方 Agent 工具。之前大量用户通过 OpenClaw 来使用 Claude 的能力。 4 天后之后，Anthropic 发布了一个名叫 Claude Managed Agents 公测版，这是一套托管式 Agent 构建和部署平台。OpenClaw 用社区的力量验证了 “Agent 即服务” 的市场需求，Anthropic 说，你别用我的服务，我要自己玩了。 这种操作并不陌生。苹果做过，Google 也做过，第三方生态验证需求，平台直接下场收割，不过现在 OpenAI 也是平台了，那就是各做各的。Anthropic 的节奏很快——从限制使用到发布自己的产品只隔了 4 天，几乎是同一个动作的两面。 Managed Agents 到底是啥呢？ 我的理解是：Managed Agents 的核心是一个三层解耦架构。Anthropic 把 Claude Code 里的那套 Harness，装到了这个平台上。 第一层是 “大脑”，其实就是 Claude 模型加 Harness。Harness 负责 prompt 循环、工具调用决策、多轮上下文管理，模型会自动评估执行结果，发现不对就回退重试，直到任务完成。 第二层是 “手脚”，Managed Agents 提供了独立的沙箱执行环境。预装了 Python、Node.js、Go，可以跑代码、操作文件、访问网络。关键的安全设计是：认证凭据存储在沙箱之外，Claude 生成的代码无法直接接触敏感 token。 第三层是 “记忆”，提供了只增不减的事件日志系统。Agent 的所有行为都会被持久化记录，支持断线重连。Agent 可以在后台自主运行数小时，即使中间出现中断也不会丢失进度。（类似 Claude-mem） 在我看来，这就是 Claude Code 平台化了，隐藏在 CC 里的 Harness 也具象化了，因为 Agent 就等于 Model 加 Harness。A 厂为企业提供了一套用更简单的方式构建企业 Agent 能力。 作为一个从业者，我的直觉是：Managed Agents 的发布传递了一个新的信号：竞争的重心正在从模型层下移到基础设施层。一套经过打磨的 Harness，才是真正的护城河，Anthropic 显然想把这条护城河掌握在自己手里，并且平台化。 A 厂表示，已经有一批公司在用 Managed Agents 了。Notion 让用户在工作区里把任务直接交给 Claude；Rakuten 为产品、销售、营销、财务、HR 等多个部门都部署了专用 Agent，一周落地一个。 这些案例有一个共同点：它们用的是同一个模型，差异全在 Harness。 这不就是龙虾吗？只不过 OpenClaw 目前面向个人，A 厂指向的是企业。 —
