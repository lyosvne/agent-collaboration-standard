## 1. 自进化系统的闭环模型

一个完整的自进化多智能体系统必须闭合六个环节，缺任何一环都会退化为"一次性工具集合"：

```
        ┌──────────────────────────────────────────────┐
        │                 用户（战略/裁定）               │
        └──────────────────────┬───────────────────────┘
                               ▼
  ①感知 ──→ ②决策 ──→ ③执行 ──→ ④验证 ──→ ⑤沉淀 ──→ ⑥进化
  (状态/漂移  (路由/优先级  (编码/生图   (评审/测试   (记忆/知识   (新工具/新技能
   /指令)     /审批)       /前端/批量)  /互检)       /真值)       /新能力上线)
     ▲                                                    │
     └────────────────── 反哺闭环 ─────────────────────────┘
```

## 7. 目标层职能补全（M 系列，响应 G6 补充）

G1-G7 闭合的是"运转环"，M 系列闭合的是"方向环"——没有方向环，系统会高效地跑向错误的地方。

| # | 职能 | 内容 | 建议承接 |
|---|------|------|---------|
| M1 | **北极星锚 + 轨道校准** | 唯一长期目标固化为版本化文档（继承 Aetheris soul.yaml/终局定义血统）；定期校准仪式：实际进化轨迹 vs 北极星比对，偏航则发回轨提案 | 北极星: **用户**定（Qoder 起草）；校准节律: **Pi** cron 触发；校准报告: **Qoder**；评审: **Mira**；回轨裁定: **用户** |
| M2 | **进化度量体系** | 无度量不可校准。定义系统健康 KPI：任务成功率/返工率/漂移事件数/成本(AFP+账单)/周转时长 | 指标定义: **Qoder**；数据采集: **Pi**（持有全部调度与审计数据）；月报: 飞书+Aetheris |
| M3 | **能力退化检测与回滚** | G6 把住入口，M3 提供出口：新 Extension/Skill 上线带观察期，指标退化即隔离（quarantine）并可回滚 | 执行: **Pi**；退化判定: **Mira**（评审职能延伸）；回滚裁定: 观察期内自动，出观察期走用户审批 |
| M4 | **记忆老化治理** | 防知识腐坏：定期审计各层记忆（agent 记忆/Aetheris/未来 OpenViking），过期修剪、矛盾标记、错误修正（本项目已三次实证记忆错误需纠偏） | 主导: **Qoder**（记忆层规划延伸）；各 agent 自审自己的记忆；矛盾仲裁: 用户 |
| M5 | **系统免疫与紧急制动** | 异常行为检测（agent 偏离规格的行为模式）+ 一键停机：飞书紧急制动卡片 → Pi 停止 cron、调度和能力晋级 | 异常检测: **Pi** supervisor；制动触发: **用户**（飞书一键）；恢复: 用户确认后 Pi 逐项重启 |

### 方向环闭合检查

```
北极星(M1锚) → 度量(M2测) → 校准(M1比对) → 偏航发现
     ▲                                        │
     │            ┌── 点状偏差 → 容忍/记录 ────┤
     └── 回到轨道 ─┴── 趋势偏航 → 回轨提案 → 用户裁定
                      能力退化 → M3隔离回滚
                      记忆腐坏 → M4修剪
                      行为异常 → M5制动
```

**结论：G(运转环) + M(方向环) 双环闭合，系统才是"可自进化且不会跑丢"的。**
