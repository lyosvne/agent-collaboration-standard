# Handoff Protocol

Minimum handoff fields:

- Goal:
- Source of truth:
- Verification:
- Next action:

Recommended full handoff fields:

- Owner:
- Branch / commit:
- Changed:
- Not changed:
- Verified:
- Not verified:
- Risks:
- Rollback:
- Files touched:
- Files intentionally avoided:

## Finish State

When claiming task completion, report:

- Changed:
- Verified:
- Not verified:
- Risk:
- Commit / PR:
- Handoff:
- Rollback target:
- Rollback method:
- Rollback verification:
