# Verification Protocol

Evidence comes before completion claims.

Common proof requirements:

- Build passes: fresh build exits 0.
- Tests pass: fresh test command exits 0 and failure count is known.
- Bug fixed: original symptom or regression check passes.
- Documentation changed: links, references, and source-of-truth alignment checked.
- Ready to commit: scoped diff, diagnostics, and dirty-state review.
- Ready for handoff: source of truth, scope, verification, risk, next action.

If verification is skipped, state it plainly.
