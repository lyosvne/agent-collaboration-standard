### 2.1 `redact-tokens.py` 无法解析

`scripts/redact-tokens.py:25-27` 的 `Path(...)` 缺少右括号：

```python
REPO = Path(__import__("os").environ.get(
    "REPO_ROOT",
    str(Path(__file__).resolve().parents[1]))
```

实际语法检查结果：

> `SyntaxError: '(' was never closed`

因此“6 个 scripts 全切换”并未成立：该脚本现在完全不可执行，属于本提交引入的新阻断。

**修法：**

```python
import os

REPO = Path(
    os.environ.get(
        "REPO_ROOT",
        str(Path(__file__).resolve().parents[1]),
    )
)
```

  `~/Documents/trae_projects/agent-collaboration-standard`

这会使 dry-run 在独立 clone 中审计另一个固定 checkout，仍存在跨 checkout 混读问题。

**修法：**将目标仓库根改为脚本位置推导，并允许 `REPO_ROOT` 覆盖；之后由 `DST_ROOT` 派生所有 Git 目标路径。
